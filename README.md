# Grimhold

Браузерная MMORPG в мрачном средневековом фэнтези: открытый мир, PvP-флаги,
расовое ремесло и подземелья с extraction-механикой.

Дизайн-документ и дорожная карта — [DESIGN.md](DESIGN.md).

## Запуск

```bash
npm install
npm run dev
```

Сервер поднимается на `ws://localhost:8080`, клиент на `http://localhost:5173`.
Кликни по экрану, чтобы захватить мышь.

Сначала создай учётную запись, потом персонажа: раса отвечает за ремесло,
класс — за боевую роль.

**Движение:** WASD, Пробел — прыжок, Shift (держать) — бег за стамину,
Alt (зажать) — показать имена.
**Бой:** ЛКМ — быстрый удар, СКМ — тяжёлый, ПКМ (держать) — блок,
Ctrl — рывок в сторону движения (с откатом), 1…6 — панель горячих клавиш.
**Рост:** навыки качаются сами от того, чем пользуешься; за победы копится
опыт персонажа, и очко из него вкладывается в жизнь, стамину или ману вручную
— правая колонка в рюкзаке.
**Вещи:** Tab — рюкзак, ею же или Esc — закрыть; двойной щелчок надевает
или применяет, перетаскивание мышью раскладывает, R в перетаскивании поворачивает.
**Мир:** E — добыть ресурс, открыть казну, мешок или сундук, спуститься
по лестнице и выйти порталом; T — предложить обмен тому, на кого смотришь;
G — позвать в отряд того, на кого смотришь, или, глядя в пустоту, принять
приглашение. Факел надевается во вторую руку (в том числе с панели) и той же
клавишей гасится: он светит, но выдаёт — и щит туда уже не взять.
**Прочее:** Enter — сказать рядом, Shift+Enter — общий канал, Esc — отпустить мышь,
F1 — настройки картинки, F11 — во весь экран.

Пока мышь захвачена, клавиатура принадлежит игре: браузерные умолчания вроде
прокрутки пробелом, поиска по «/» и Ctrl+S гасятся. Ctrl+W, Ctrl+T и подобное
страница отобрать не вправе — их отдаёт только полный экран (F11) и только
в Chromium. Обновление (F5, Ctrl+R) и отладка (F12) не перехватываются никогда.

Чтобы проверить мультиплеер, открой вторую вкладку с другим именем:
`http://localhost:5173/?name=Второй`

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сервер и клиент вместе |
| `npm run dev:server` | только сервер |
| `npm run dev:client` | только клиент |
| `npm test` | юнит-тесты симуляции |
| `npm run typecheck` | проверка типов всех пакетов |
| `npm run e2e` | сквозной тест против живого сервера: вход, чат, сохранение, радиус интереса |
| `npm run netcode` | проверка предсказания под задержкой и потерями |
| `npm run combat` | сквозной тест боя: удары, стамина, мобы, лут, смерть |
| `npm run gate` | что из города можно выйти и за воротами есть земля |
| `npm run seed` | создать тестовую учётку `test` / `test123` с тремя персонажами |

## Структура

```
packages/
  shared/   протокол, шаг симуляции, генерация чанков, расы и классы — общий код
  server/   авторитарный сервер: тик 20 Гц, слой команд, сессии, хранилище, инстансы
  client/   three.js: рендер, предсказание, интерполяция, экраны входа, чат
scripts/    проверочные скрипты, работающие против живого сервера
```

## Что уже работает

**Сеть.** Сервер авторитарен, клиент предсказывает своё движение и переигрывает
непринятые вводы поверх авторитетного состояния. Чужие игроки интерполируются
с задержкой 110 мс. При 150 мс и 2% потерь средняя поправка — доли сантиметра.

**Мир.** Город собран вручную, дикие земли вокруг генерируются детерминированно
из координат чанка, поэтому сервер и клиент получают одинаковую геометрию, не
пересылая её по сети. Чанки подгружаются и выгружаются на ходу.

**Аккаунты.** Пароли хранятся как scrypt-хеш с солью. До трёх персонажей на
аккаунт, раса и класс независимы. Позиция и время в игре переживают перезаход.

**Радиус интереса.** Сервер шлёт только то, что в 45 метрах: и трафик меньше,
и данных о далёких игроках у клиента физически нет.

**Чат.** Enter — сказать рядом (слышно в радиусе интереса), Shift+Enter — общий канал.

**Бой.** Реальное время, три фазы: замах, удар, восстановление. Замах видно, поэтому
от удара можно отойти, поставить блок или перебить своим быстрым ударом. Попадание
проверяет сервер, отматывая цели назад по истории позиций — игрок бьёт по тому,
что видел на экране, а не по тому, где цель уже оказалась.

**Стамина** тратится на удары, блок и рывок и восстанавливается только после паузы:
блок нельзя держать вечно. Рывок даёт неуязвимость на время самого броска.

**Мобы.** Шесть типов, конечный автомат «дремлет → заметил → преследует → бьёт →
возвращается». Чем дальше от города, тем опаснее: у города крысы и волки, на краю
мира огры и умертвия. С убитых падает лут по таблицам.

**Магия.** Шесть заклинаний. Снаряды летят настоящим телом, а не мгновенным лучом:
от «Уголька» можно отойти, а «Разряд» с его долгим кастом наказывает за неподвижность.

**Навыки** растут от использования — учит только результат, удар в пустоту не тренирует.
Глобального уровня нет: разрыв между новичком и ветераном примерно двукратный,
и это осознанно — в подземелье с полной потерей вещей новичку должно быть что ловить.

**Ресурсы и ремесло.** Начинаешь с пустыми руками: ветка с сухостоя, камень с осыпи,
волокно с куста берутся без всякого инструмента, и из них вяжутся нож, топор и кирка.
Дальше топор открывает бревно, кирка — руду, нож — травы. Добыча занимает время
и показывается полосой: отошёл — бросил работу, и стоять у ноды в диких землях
небезопасно. Простое делается где угодно
и без рецепта, остальное — по свиткам и только своей расой, поэтому расам есть о чём
договариваться. Изготовление занимает время и показывается полосой.

**Казна** в городе — единственное место, где вещи не пропадут. Хранилище общее на все
твои персонажи. Обмен между игроками — лицом к лицу, с подтверждением с обеих сторон.

**Смерть** в открытом мире вещей не отнимает: возврат в город и путь обратно.
Полная ставка — внизу.

**Подземелья.** Люк на площади, у каждого забега своё зерно и свой зал
на двенадцать человек. Три этажа, каждый нарезан на девять комнат с проходами;
лестницы вниз и наверх — в нишах со знаками, и цвет знака говорит, куда он
ведёт. Глубже — злее обитатели и богаче сундуки. Видно на пять с половиной
метров, постоянного огня внизу нет: свет приносят с собой, и факел занимает
руку вместо щита да ещё и выдаёт тебя. Внизу флаги не действуют — все всем
враги, и своих отличает только отряд.

**Конец вылазки.** На дне стоит «Хозяин глубины». Пока он жив, порталы заперты
всему инстансу; его смерть открывает их на две с половиной минуты, и сигнал
получают все сразу. Опоздавшему остаётся смерть — надетое пропадает, рюкзак
остаётся мешком на полу и достаётся тому, кто дойдёт.

**Руки от первого лица.** Отдельная сцена поверх мира с очисткой буфера глубины —
иначе вплотную к стене руки уезжали бы внутрь геометрии. Анимация привязана к тем же
фазам замаха и удара, по которым сервер считает попадание, поэтому картинка не врёт:
кулак выброшен ровно тогда, когда удар засчитывается. Замах стартует по нажатию,
не дожидаясь ответа сервера, — но только если стамины хватает, а это то же правило,
по которому сервер откажет. Габариты рук берутся из профиля расы.

## База данных

Локально — SQLite через встроенный в Node `node:sqlite`, файл `grimhold.db`.
Весь доступ идёт через интерфейс `Storage`, поэтому PostgreSQL на проде будет
второй реализацией рядом, а не переделкой сервера.

Политика записи описана в [DESIGN.md](DESIGN.md) и реализована в
`packages/server/src/persistence.ts`: пакетный флаш раз в минуту для всего,
что не жалко, и немедленная запись критичных событий, чтобы падение сервера
не порождало дюп предметов.

## Ассеты

Только CC0: модели KayKit, текстуры Poly Haven, скелет собран из примитивов
в коде. Источники, правила и почему Unity Asset Store не годится —
[docs/assets.md](docs/assets.md).

## Устройство

Монорепа на TypeScript: `packages/shared` (общий код клиента и сервера),
`packages/server` (авторитарный сервер), `packages/client` (three.js),
`scripts` (проверки против живого сервера).

Три правила, на которых всё держится: клиент шлёт намерения, а не результаты;
состояние мира меняется только слоем команд; операции с ценностями пишутся
в базу немедленно. Обоснования и подробности — [docs/architecture.md](docs/architecture.md)
и [docs/storage.md](docs/storage.md).
