# Веб-MMORPG: dark fantasy, 3D от первого лица, extraction-подземелья

## Context

`d:\project1` пуст — начинаем с нуля. Браузерная MMORPG в мрачном средневековом фэнтези,
вдохновлённая Meridian 59, объединяющая четыре системы: открытый мир, PvP-флаги в духе Lineage,
расовое ремесло в духе Valheim и подземелья с extraction-механикой в духе Dark and Darker.

**Решения по геймплею и технике (согласованы):**

- 3D от первого лица на three.js; открытый мир строим первым.
- Реалтайм-бой со стаминой, блоком и уклонением.
- Смерть в подземелье = полная потеря всего, что было на персонаже. Инвентарь-сетка с размерами предметов.
- Ассеты: блокаут-геометрия сначала, бесплатные паки и Mixamo потом.
- Netcode: авторитарный сервер, предсказание + реконсилиация с первой вехи.
- Мир гибридный: бесшовная наземная область с чанками, интерьеры и подземелья — инстансы.
- **Инстансы без отдельных мап-левелов:** геометрия интерьеров лежит в том же мировом пространстве
  со смещением, изоляция обеспечивается полем `instanceId` и фильтрацией снапшотов на сервере.
- **Античит не пишем на старте**, но протокол и слой команд закладываем так, чтобы его навесить без переделки.
- Ник над головой виден только при зажатой клавише.
- Выход из подземелья открывается убийством сильного монстра. Никакого сжимающегося круга тьмы.

**Объём.** Строим вертикальный срез: один город, одна наземная область, одно подземелье на 3 этажа,
~6 типов мобов, 30-50 игроков на шард. Дальше — контент поверх готовых систем, не новый код.

## Расы, классы и ремесло

Расы и классы независимы: **3 расы × 3 класса**.

- Классы (боевая роль, навыки растут от использования): **Воин**, **Следопыт**, **Маг**.
- Расы (ремесло, атрибутные модификаторы): **Человек**, **Дворф**, **Эльф**.

Ремесло без станков — крафтить можно где угодно, в два яруса:

| Ярус | Кто | Что | Рецепт |
|---|---|---|---|
| Базовый | любой персонаж | бинты, факелы, стрелы, грубые инструменты, простое снаряжение | не нужен |
| Рецептурный | только своя раса | — | нужен изученный свиток |
| — Дворф | | металлическое оружие и броня | |
| — Эльф | | зелья и бафы | |
| — Человек | | деревянное оружие, луки, тканевая и кожаная экипировка | |

**Свитки рецептов среднего и сильного снаряжения падают только в подземельях** и читаются лишь
соответствующей расой. Так подземелье остаётся источником силы, ремесло даёт расам взаимную
нужность, а торговля между игроками возникает сама.

## Архитектура

Монорепозиторий на TypeScript, три пакета — иначе игровую логику придётся писать дважды:

```
d:\project1
├─ packages/
│  ├─ shared/    протокол, шаг симуляции движения, формулы урона, предметы и рецепты
│  ├─ server/    Node + ws, авторитарный тик 20 Гц, зоны, инстансы, персистентность, Prisma
│  └─ client/    three.js, рендер, ввод, предсказание, HTML-оверлей UI
```

**Единый шаг симуляции.** `shared/movement.ts` экспортирует чистую функцию
`step(state, input, dt) -> state`, которую вызывают и клиент (предсказание), и сервер (авторитет).
Две расходящиеся реализации — источник почти всех багов реконсилиации, поэтому код ровно один.

**Стек:** TypeScript, three.js, Vite, Node 20 + `ws`, Prisma (SQLite локально → PostgreSQL на проде),
Zod для схем пакетов, Vitest для формул. Redis не нужен, пока шард один.

### Готовность к античиту (без античита)

Два правила, соблюдаемые с первой строки. Сами по себе бесплатны, но без них античит потом = переписывание.

1. **Клиент шлёт намерения, а не результаты.** `{тип: атака, направление, seq}` — не «я нанёс 50 урона».
   `{ввод за кадр, seq}` — не «моя позиция теперь X,Y,Z». Сервер вычисляет всё сам.
2. **Единственный путь мутации.** Всякое изменение состояния проходит через слой обработчиков команд
   (`server/commands/*`) с общей сигнатурой `(actor, payload, world) -> events`. Ничто не меняет
   состояние в обход.

Тогда античит — это дописывание проверок внутрь существующих обработчиков (дистанция удара, кулдаун,
стамина, доступность рецепта, вес, темп команд), то есть дни работы, а не месяцы.

Побочная выгода: interest management (сервер шлёт только сущности в радиусе видимости) нужен с самого
начала как оптимизация трафика и заодно закрывает wallhack — данных о невидимых игроках у клиента нет.

### Персистентность: батчинг вместо шторма инсертов

Во время игры источник истины — **память сервера**. БД это слой долговечности, не операционное хранилище.

1. **Dirty-flag + write-behind.** У сущности флаг «изменилась». Раз в 60-120 с один батч в одной
   транзакции пишет только изменившихся. Десятки действий между флашами схлопываются в одну запись.
2. **Белый список критичных событий пишется немедленно и синхронно.** Иначе краш сервера откатывает
   состояние и порождает дюп предметов — классическая смерть экономики MMO. Сразу пишем: результат
   выхода из подземелья, завершение обмена, смерть с потерей лута, операции с банком, вход и выход
   из игры. Это единицы событий в минуту на весь сервер. Позиция, HP, прогресс навыков, подобранный
   лут — терпят батч.
3. **Форма хранения.** Инвентарь — один JSON-столбец в строке персонажа, не строка на предмет:
   сохранение = один UPDATE вместо сорока INSERT. Разносим на строки только когда понадобится
   искать предметы по миру (аукцион).
4. Принудительный флаш при выходе игрока, смене зоны и штатной остановке сервера.

Худший случай краша — минута прогресса, но не предметы.

## Веха 3 — Бой, персонаж, мобы — ГОТОВО

Сделано сверх плана: снаряды заклинаний летят настоящим телом (их можно уворачивать),

### Дальний бой: чем ограничен и чем платит

Найдено при разборе: **лук был предметом без выстрела** — урон 18, рецепт,
свиток, а удар с ним шёл рукопашным профилем на 2.4 метра. Стрелы крафтились
и не тратились никем. Теперь выстрел есть, и устроен он как снаряд заклинания:
полёт телом, попадание по коробке, столкновение с камнем — всё это уже
работало для магии.

Потолок дальности задаёт **не вкус, а сеть**: сервер присылает чужих в радиусе
интереса, и стрелять дальше — значит стрелять в того, кого тебе не показывают.
Отсюда правило для любого дальнобойного оружия, нынешнего и будущего:
**дальность заметно ниже радиуса интереса**, чтобы цель была видна раньше, чем
войдёт в дальность. И следствие: захотел стрелять дальше — поднимай радиус,
а это уже трафик, который надо мерить.

| | Лук | Магия |
|---|---|---|
| дальность | 45 м (радиус интереса 58) | 28 м «Уголёк», 32 м «Разряд» |
| урон на дистанции | полный до 12 м, дальше спад до 40% | ровный на всей дальности |
| чем платишь | стрелой за выстрел | маной и долгим кастом |
| скорость снаряда | 55 м/с, почти плоско | 24 и 42 м/с |

Спад урона у стрел — намеренная асимметрия. Магия дорога и медленна, поэтому
бьёт одинаково везде; лук дёшев и быстр, поэтому платит расстоянием. Без спада
он стал бы снайперской винтовкой: отошёл на предел и расстреливай безнаказанно.

Тяжести у снарядов нет — летят по прямой, вертикаль ничем не ограничена.
Навесная стрельба и падение стрелы придут вместе с настоящей моделью лука,
если придут: сперва надо увидеть, чего не хватает в бою.

*Проверка:* убиваешь моба, получаешь лут, навык растёт; бой отзывчив под пингом.

## Веха 4 — Инвентарь и ремесло

Инвентарь-сетка с размерами предметов (меч 1×4, зелье 1×1) — раскладку хранит и валидирует сервер,
клиент только рисует. Слоты экипировки, вес, влияние веса на скорость и стамину.
Ресурсные ноды в мире (6 типов) с респауном и требованием инструмента.
Базовый крафт без рецептов для всех. Рецептурный крафт с расовой привязкой и свитками.
Банк в городе — единственное безопасное хранилище. Прямой обмен между игроками.

*Проверка:* срубил дерево → сделал стрелы без рецепта; эльф читает свиток зелья, дворф тот же свиток
прочесть не может; обмен переживает перезапуск сервера.

## Веха 5 — PvP-флаги

Белый (мирный) → фиолетовый (в бою, отвечать безнаказанно, по таймеру) → красный (убил белого, карма).
Красный при смерти рискует дропнуть экипированную вещь и получает штраф к навыкам; карма снимается
временем и PvE. Безопасные зоны (город, стартовая область) — атака отклоняется сервером.
Группы с метками на своих.

*Проверка:* атаковал белого — стал красным; в городе атака невозможна.

## Веха 6 — Extraction-подземелье (главная фишка)

Инстанс на 12 игроков, соло и группы вместе, изоляция через `instanceId`. Процедурная сборка 3 этажей
из готовых комнат-блоков; глубже — лучше лут и злее мобы. Внутри флаги не действуют, все всем враги.
Сундуки вскрываются с задержкой (уязвим и слышен). Темнота — механика: факел выдаёт тебя издалека,
ник по зажатой клавише не даёт опознать силуэт мгновенно.

**Выход:** на нижнем этаже сильный монстр. Пока он жив, порталы закрыты для всех.
Его смерть открывает порталы **всему инстансу** на 2-3 минуты, и все получают об этом сигнал.
Это создаёт естественную PvP-развязку: слабые ждали сильных, а теперь все бегут к одним и тем же
порталам с полными карманами. Активация портала занимает несколько секунд.
Успешный выход переносит всё в город и пишется в БД немедленно; смерть теряет всё.
Бесплатный стартовый набор делает вход всегда доступным, поэтому страховка не нужна.

*Проверка:* полный забег с двух машин — вход, лут, босс, открытие порталов, встреча, бой,
выход одного и смерть другого; инвентари в БД соответствуют исходу; краш сервера сразу после
выхода не дюпит предметы.

## Веха 7 — Атмосфера и содержание

Замена блокаута на бесплатные паки (Quaternius, Kenney) и анимации Mixamo, пайплайн GLTF.
День и ночь, туман, звук — шаги, оружие, эмбиент подземелья (в extraction-игре звук это половина
напряжения). Вторая наземная зона. Личные сообщения. Docker, VPS, домен.

## Осознанно откладываем

Античит-проверки (архитектура готова), отдельные мап-левелы для инстансов, кланы и войны, аукцион,
рейды, маунты, несколько шардов, бинарный протокол, мобильную поддержку.

Два замечания по ощущениям разобраны и оставлены как есть — **осознанно, а не забыто**:
заметность травы среди декоративной зелени и низкий прицел у стелющихся нод (травы, волокна).
Трогать их без отдельной просьбы не надо: цена правки не в коде, а в том, что она меняет
читаемость диких земель целиком.

## Первые задачи (стартуем сразу)

**Задача 0 — документ.** Сохранить этот дизайн в проект как `d:\project1\DESIGN.md` (расы и ремесло,
правила античит-готовности, политика персистентности, механика выхода из подземелья) — опорный
документ, который правим по ходу.

**Задача 1 — каркас монорепы.**
`package.json` с npm workspaces, `packages/shared|server|client`, общий `tsconfig.base.json`
с path-алиасами, Vite для клиента, `tsx watch` для сервера, `npm run dev` поднимает оба.

**Задача 2 — протокол.**
`shared/protocol.ts`: версия, Zod-схемы пакетов. Клиент → сервер только намерения:
`Join`, `Input {seq, forward, right, yaw, pitch, jump, dt}`. Сервер → клиент:
`Welcome {playerId, tickRate}`, `Snapshot {tick, lastProcessedSeq, entities[]}`.

**Задача 3 — симуляция.**
`shared/movement.ts`: чистая `step(state, input, dt) -> state` со скоростью, гравитацией, прыжком
и капсульной коллизией по списку AABB. Юнит-тесты в Vitest: не проваливается, не проходит стены,
детерминирована при одинаковом вводе.

**Задача 4 — сервер.**
Цикл 20 Гц с фиксированным шагом, `ws`-сервер, слой команд `server/commands/*` с сигнатурой
`(actor, payload, world) -> events`, буфер ввода на игрока, рассылка снапшотов. Пока in-memory, без БД.

**Задача 5 — клиент.**
three.js сцена, pointer lock, камера от первого лица, бокс-уровень как массив AABB (тот же,
что у сервера, из `shared`), отправка ввода, применение снапшота напрямую (предсказание — веха 2).

*Готовность:* `npm run dev`, открыл браузер, ходишь по карте, упираешься в стены,
сервер логирует твой ввод.

   инструмента **в руке**. Раскладка детерминированная в `shared/nodes.ts`,
   сервер хранит только тронутое. Приёмка — `npm run harvest`.
4. ~~Крафт~~ — готово: базовый ярус без рецептов для всех, рецептурный —
   с расовой привязкой и свитками. Свитки пока роняет умертвие, по замыслу
   они падают в подземельях. Приёмка — `npm run craft`.
5. ~~Банк в городе~~ — готово: каменный ларь на площади, хранилище общее на
   аккаунт, каждая операция пишется в базу немедленно. Приёмка — `npm run bank`.
6. ~~Прямой обмен между игроками~~ — готово: стол на двоих, любое изменение
   снимает оба подтверждения, сделка проходит целиком или не начинается.
   Приёмка — `npm run trade`.

**Веха 4 закрыта.** Идёт веха 5 — PvP-флаги:

1. ~~Безопасные зоны~~ — готово: город внутри стен, правило одно на удары
   и снаряды (`server/src/pvp.ts`), проверяются оба участника. Приёмка —
   `npm run pvp`.
2. ~~Флаги и карма~~ — готово: белый, фиолетовый, красный; флаг выводится из
   кармы и таймера, а не хранится. Красный при смерти теряет часть опыта
   навыков и **рискует** одной надетой вещью. Приёмка — `npm run pvp`.
3. **Группы** — перенесены в веху 6: в открытом мире собираться пока не ради
   чего, а в подземелье группа часть замысла и проверяется сразу в деле.

**Веха 5 закрыта.** Идёт веха 6 — подземелья с выносом добычи, главная фишка
и самая большая работа. Порядок нарезки (пункты 2 и 3 поменялись местами осознанно: добыча без риска —
бесплатные конфеты, смерть без добычи — пустое наказание, вместе они играбельный
срез):

1. ~~Вошёл — вышел~~ — готово: инстанс с зерном в имени, люк на площади, зал
   с колоннами, портал наружу, вещи едут в обе стороны. Приёмка —
   `npm run dungeon`. Подробности — [docs/dungeon.md](docs/dungeon.md).
2. ~~Сундуки~~ — готово: раскладка из зерна, вскрытие полосой пять секунд
   (уязвим и слышен), свитки рецептов переехали сюда с умертвия. Зал заселён
   своей нежитью, состав тоже из зерна.
3. ~~Смерть внизу~~ — готово: убитый теряет надетое насовсем, рюкзак остаётся
   мешком на полу и достаётся тому, кто дойдёт. Зал при этом стал общим —
   на двенадцать человек, как и было задумано: без второго живого мешок
   некому найти.
4. **Этажи**: процедурная сборка трёх этажей из комнат-блоков, глубже — злее.
5. **Темнота и факел** — свет как механика, а не как настройка.
6. **Босс и порталы**: пока жив — выхода нет, его смерть открывает порталы
   всему инстансу. Это и есть кульминация забега.
7. **Группы** — перенесены из вехи 5, проверяются здесь же.

Два шага дальше по дороге, которые дешевле заложить сейчас, чем переделывать:

- **Дельта-снапшоты.** Снапшот по-прежнему полный, но опознание сущностей
  (имя, вид, раса) теперь едет один раз, а не двадцать раз в секунду: на сорока
  игроках это 3.6 КБ вместо 5.7 и 70 КБ/с вместо 111. Сервер считает тик за 1 мс
  из 50 — упрётся всё равно сеть, а не расчёт, просто позже.
- **Переносной свет как механика подземелья** — факел в руке. Архитектура
  под это готова (пул ламп), но брать его надо вместе с вехой 6, не раньше.
